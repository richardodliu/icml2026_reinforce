# REINFORCE++ — ICLR 2027 source

Main file: `main.tex`. This is the anonymous review version.

## Build

```sh
latexmk -pdf main.tex
```

For Overleaf, upload this source directory and select `main.tex` with the pdfLaTeX compiler.

## Contents

- Official ICLR 2027 style and bibliography files, unmodified.
- `sections/`: manuscript text and appendices.
- `references.bib`: references cited in the manuscript.
- `imgs/`: experimental figures.
- Appendix A: response-wise token mean followed by batch mean loss.

Official template: https://media.iclr.cc/Conferences/ICLR2027/iclr-2027-style-files.zip

Keep `\iclrfinalcopy` disabled for double-blind review.
