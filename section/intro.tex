\section{Introduction}

Reinforcement Learning from Human Feedback (RLHF) is used to align Large Language Models~(LLMs) with human values and preferences ~\citep{vemprala2023chatgpt,achiam2023gpt, Ouyang2022, shen2024policy,shen2025exploring,hu2024openrlhf}. Alongside preference-optimization methods such as DPO ~\citep{rafailov2023direct}, systems including ChatGPT/GPT-4 ~\citep{vemprala2023chatgpt, openai2023gpt4}, Claude ~\citep{anthropic2023introducing}, and Gemini ~\citep{team2023gemini} have incorporated reinforcement learning into post-training.

A widely used RL algorithm in this setting is Proximal Policy Optimization (PPO) ~\citep{schulman2017proximal}. In actor--critic implementations of PPO, a learned value function provides a baseline for estimating advantages. Training this value network adds computation and memory costs \citep{shao2024deepseekmath}.

REINFORCE-based methods replace the learned critic with reward-based baselines. Examples include ReMax~\citep{li2023remax}, RLOO~\citep{2024Back}, and GRPO~\citep{shao2024deepseekmath}. These algorithms construct reward-based baselines using greedy decoding or multiple sampled responses to the same prompt.

These critic-free methods differ in their approach to \textit{advantage estimation}. GRPO uses \textbf{prompt-level (local) normalization}, estimating a baseline and standard deviation from responses to one prompt; RLOO uses a leave-one-out baseline without inherently requiring this scale normalization. First, Appendix~\ref{appendix:proof_GRPO} shows that finite-sample self-normalization differs from population standardization. Second, small groups (e.g., $k=4$ or $k=8$) make the scale sensitive to sampled outcomes. Homogeneous groups provide no centered reward signal, while different reward spreads induce different prompt-specific scales. Prompt-specific scales also change the relative weighting of reward differences across prompts. Our experiments examine the resulting training dynamics and held-out generalization.

We introduce \ours, a framework with two variants centered on global advantage normalization. The basic variant supports $k \ge 1$. It samples one response per prompt when $k=1$ (Algorithm 1), and supports multiple responses when $k>1$ (Section 4.2). \varn is a \textit{variant} for complex tasks ($k>1$) that constructs a local reward baseline from \textbf{group sampling}. It separates reward centering from scale estimation by first subtracting the \textit{group mean} (for within-prompt comparisons) and then normalizing by the \textit{global standard deviation} (for a shared batch scale). It also employs a $k_2$ gradient surrogate for separate $\mathrm{KL}$ regularization, as detailed in Appendix~\ref{appendix:kl_design}. Our contributions are:
\begin{itemize}
    \item We bound self-normalized rewards and characterize their finite-sample conditional expectation under Gaussian sampling (Appendix~\ref{appendix:proof_GRPO}).
    \item We propose \ours, a critic-free framework centered on Global Advantage Normalization, to share normalization statistics across prompts while retaining PPO clipping.

    \item We present two algorithms: \ours supports $k \ge 1$ for general RLHF and reasoning, while \varn combines group-mean reward centering with global normalization for $k>1$.

    \item The experiments show that \ours achieves competitive general RLHF scores with shorter responses than GRPO and higher held-out reasoning scores. The baseline variant achieves higher mean accuracy than GRPO and PPO across five tool-use benchmarks.
\end{itemize}
